# Cutroom

**A local-first workspace for AI-assisted video editing.**

Cutroom helps creators shape long recordings into short-form edits. Review an AI-proposed story, edit cuts from the transcript, refine the timeline and captions, then check and export the finished video.

## Highlights

- AI-assisted story and edit-decision proposals, reviewed by the editor before approval
- Word-level transcript edits with undo and redo
- Timeline editing, captions, subject framing, and exports for multiple aspect ratios
- Render checks for audio levels, black frames, silence, and timing
- Projects and source media stored locally; cloud agents receive selected context according to provider settings

## About

Cutroom is proprietary software. This public repository is a visual project overview; it does not contain source code, build files, or an application download.
